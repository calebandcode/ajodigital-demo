# Ajo Digital — Android Demo

Ajo Digital is an offline-first mobile ledger for Nigerian market thrift collectors (*Alajos*). It replaces paper thrift cards with digital records, instant SMS receipts and simple month-end payouts.

This repository hosts **demo builds only**. The source code is private.

> **Demo notice:** this build uses **sample data** and moves **no real money**. SMS and banking features are simulated or running in sandbox.

## Download
Get the latest APK from the [**Releases**](../../releases) page.

## How to install
1. Download the `.apk` file on your Android phone.
2. Open it. If Android asks, allow installs from this source ("Install unknown apps").
3. Tap **Install**, then open **Ajo Digital**.

The app isn't on the Play Store yet, so Android may show a warning. This is normal for apps installed directly.

## What to try
- **Collector mode:** browse contributors, log a cash payment, and see the passbook update.
- **Saver mode:** view balance, passbook and payout schedule.
- Switch between modes with the **Switch** button.
